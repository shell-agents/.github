- [`AGENT_SPEC.md`](./AGENT_SPEC.md) — the wire contract every agent must satisfy

- [`CONTRIBUTING.md`](./CONTRIBUTING.md) — how to propose an agent, RFC, or PR
- [`ROADMAP.md`](./ROADMAP.md) — what we're building, in what order
- [`.github/`](./.github/) — issue templates, PR template, and the RFC process
